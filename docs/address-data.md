# Date de adrese pentru Devon

Pachetul offline actual folosește adrese și drumuri din OpenStreetMap și afișează doar intrările care există în extractul local. OpenStreetMap nu este un registru complet al tuturor locuințelor.

Royal Mail Postcode Finder este o verificare online utilă, dar datele lui provin din Postcode Address File (PAF®). Nu răzuim și nu redistribuim PAF în pachetul offline fără drepturi de utilizare. Când un postcode nu există în pachetul local, aplicația trebuie să spună clar acest lucru și poate oferi o verificare online către Royal Mail.

OS Open Names/Code-Point Open pot adăuga postcoduri și puncte geografice cu licență de date deschise, dar un punct de postcode nu este aceeași lucru cu lista completă a adreselor din acel postcode. Pentru lista completă de proprietăți este necesară o sursă de adrese autorizată.
